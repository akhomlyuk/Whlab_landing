# Редизайн визитки whlab.ru — «Консоль-герой»

Дата: 2026-10-09
Статус: на утверждении
Репозиторий: `Whlab_landing`
Заменяет: `2026-10-07-landing-design.md` (раскладка, структура, палитра — по ней остаются только контент и запреты, не отменённые здесь)

## 1. Что это

Полный редизайн главной страницы `whlab.ru`. Визитка остаётся визиткой:
статическая страница без сборки, деплой — `git pull` на nginx.

### Причина редизайна

Владелец назвал главную боль — **плотность блоков**: страница
выглядит сжатой, карточки и секции идут плотной стеной. Цвета в целом
удовлетворяют, эксперименты разрешены. Терминальный образ — эволюция,
не слом. Структура и контент полностью пересматриваются.

### Задача страницы

**Быстрая визитка.** Человек приходит и за 5 секунд понимает, кто это
и куда перейти. Всё остальное — второстепенно.

## 2. Что выбирается и почему

| Решение | Выбор | Отвергнуто |
|---|---|---|
| Общее направление | B-1 «Консоль-герой»: широкий hero + воздушная лента | B-2 bento-сетка (центр тяжести размазан), B-3 буквальная сессия терминала (промпты не тапаются на телефоне) |
| Плотность | Заметно свободнее: вертикальные отступы секций `clamp(4rem, 10vw, 7.5rem)` | статус-кво, уплотнение |
| Ширина | `min(900px, 100% - 2rem)`, одна колонка | 1180px с двумя колонками (текущее) |
| Структура | hero → about → elsewhere → best of → projects → footer | двухколоночный `grid` best of + projects |
| Акцент | Холодный голубой из уже существующей синевы; зелёный — только микро-сигналы | зелёный как главный цвет (текущее), новая палитра |
| Карточки | Без рамки, радиус 14px, ховер-подъём | сплошная рамка 1px (текущее) |
| Projects | Одна широкая карточка с тремя строками | три равные плитки |

## 3. Структура

```
враппер  min(900px, 100% - 2rem), по центру
└── main  одна колонка, без вложенности
    ├── hero        аватар, $ whoami, имя 56–80px, щит, роль,
    │               строка-био, CTA-ссылки (Telegram, GitHub)
    ├── about       био-абзац (текст из старой спеки, раздел 8)
    ├── elsewhere   лента ссылок на соцсети
    ├── best of     результаты CTF по годам
    ├── projects    одна широкая карточка-список проектов
    └── footer      copyright + переключатель темы
```

Двухколоночный `grid` (best of + projects) удаляется целиком: одиночная
колонка важнее компактности — это и есть ответ на боль по плотности.

Hero-высота `min-height: ~70vh` на десктопе с прижатием контента к
началу: первый экран не должен требовать скролла.

### Порядок секций

Порядок: hero (основные ссылки в CTA) → about (кто это) → elsewhere
(полный список, где найти) → best of (чего достиг) → projects (что
сделал). `about` стоит вторым: абзац объясняет имя из hero и даёт
контекст спискам, а полный elsewhere идёт после, потому что две
главные ссылки уже показаны в hero.

## 4. Типографика

Fluid-шкала через `clamp()` (гайд modern-web-guidance «typography»):

| Роль | Размер | Шрифт |
|---|---|---|
| Имя в hero | `clamp(2.5rem, 8vw, 5rem)`, weight 700 | Ubuntu |
| Заголовки секций | `clamp(1.5rem, 4vw, 2rem)`, weight 500 | JetBrains Mono, lowercase, с висячим `_` как промпт |
| Текст карточек | 1.0625rem | Ubuntu |
| Подписи, мета | 0.875rem | JetBrains Mono |

- `text-wrap: balance` на заголовках, `text-wrap: pretty` на абзацах.
- Межстрочный body — 1.65 (был плотнее): главный рычаг воздуха.
- Шрифты остаются локальными woff2 (`css/fonts.css` не меняется).

## 5. Цвет и детали

### Акцент

Зелёный `--accent` уходит из доминанты: остаётся только на микро-сигналах
(ховер, кубок Top 1). Главный акцент — холодный голубой из уже
существующей синевы фона: `#38BDF8`-класса в тёмной теме, темнее
(`#0369A1`-класса) в светлой. Оба значения проверяются на 4.5:1 в обеих
темах тем же приёмом, что уже применён к `--tg`. Золото `--gold`
остаётся ровно на своём месте — Top 1.

Новые токены: `--accent` переназначается на голубой,
`--signal` (или сохранённый зелёный) — для микро-сигналов. Имена
финализируются в плане, главное: роли разделены.

### Карточки

- Без сплошной рамки: фон `--surface`, радиус `--radius-lg` → 14px.
- Ховер: тень `--shadow` + `translateY(-2px)`, 150ms.
- Плитка иконки 44px, радиус 10px — размер сохраняется.
- Projects — одна широкая карточка: строка «иконка + название +
  описание» на пункт, а не три плитки.

### Hero

- Строка `$ whoami` над именем: mono, приглушённый цвет, мигающий
  курсор `▋` через `steps()`, отключается при `prefers-reduced-motion`.
- Аватар 64px (был 40), радиус 12px: слева от имени на десктопе,
  над именем на мобиле.
- CTA-пилюли: Telegram и GitHub — всегда видны, ≥44px тап.

### Что остаётся нетронутым

Логика темы (localStorage `whlab-theme`, `prefers-color-scheme`,
`theme-color`), SEO/OG-метатеги, счётчик Яндекса, манифест, favicon,
`static/*`, деплой без сборки. Ключ localStorage — свой, чтобы не
перетирать настройку ctf-catalog.

## 6. Мобильная версия (< 640px)

- Враппер `100% - 2rem`, имя сжимается до ~40px через `clamp()`.
- Hero: аватар над именем, CTA переносятся в две строки, тапы ≥44px.
- Отступы секций сползают до нижней границы `clamp()` (4rem).
- Колонок нет нигде — ломаться нечему.

## 7. Доступность

- Контраст: текст 4.5:1, не-текст 3:1 — все пары проверяются
  программно в `tools/verify.py` (WCAG-формула), включая новые
  токены голубого акцента в обеих темах.
- `prefers-reduced-motion`: курсор и hover-подъём отключаются.
- `:focus-visible` — 2px, цвет акцента, на всех интерактивах.
- Семантика: `header/main/footer`, h1 (имя) → h2 (секции) → h3 (годы),
  иконки `aria-hidden`, у кнопки темы `aria-label` (уже есть).
- Дублирование ссылок (hero CTA + полный elsewhere) — ок, оба места
  ведут на одни и те же адреса.

## 8. Проверка

1. `python tools/verify.py` — расширяется: новые токены в обеих темах,
   отсутствие `grid`-двойни, наличие footer, контраст-пары.
2. Ручной прогон в браузере: 375 / 768 / 1440px, обе темы,
   reduced-motion.
3. Контраст — скриптом, не на глаз.
