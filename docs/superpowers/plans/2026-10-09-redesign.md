**Goal:** Полный редизайн главной whlab.ru по спеке «Консоль-герой»: широкий hero с `$ whoami`, воздушная одноколоночная лента, холодный голубой акцент вместо зелёного доминирования.

Перестраиваются три файла: `css/tokens.css` (новые роли акцентов), `index.html` (структура hero → about → elsewhere → best of → projects → footer), `css/style.css` (одна колонка, fluid-типографика, ховер-подъём). `tools/verify.py` расширяется проверками, которые превращают решения спеки в машинные инварианты: контраст-пары в обеих темах, отсутствие grid-двойни, наличие footer, строка `$ whoami`, отключение анимаций при reduced-motion.

**Tech Stack:** тот же: HTML + CSS-токены + ~40 строк инлайн-JS темы. Проверки — `python tools/verify.py`, голый стандартный Python.

**Spec:** `docs/superpowers/specs/2026-10-09-redesign-design.md`

## О границах этого плана

План несёт то, что невозможно вывести и что уже проверено расчётом: точные значения токенов (контраст посчитан по WCAG-формуле), точные тексты, точные URL, полный код новых проверок верификатора. Визуальный слой `style.css` — форма вокруг этих значений — пишется по спеке §3–§6 исполнителем; дублировать тут триста строк вёрстки значит сделать план нечитаемым, а не точным.

## Global Constraints

- **Сборки нет.** Ни бандлера, ни npm. `git pull` на nginx — и всё.
- **Имя везде `Exited3n`** — слитно, с цифрой `3`.
- **Тёмная тема — референсная** в `:root`; светлая — `[data-theme='light']` и зеркальный `@media (prefers-color-scheme: light)` с `:root:not([data-theme])`. Оба светлых блока побайтно одинаковы (ловит `check_light_palette_consistency`).
- **Ключ темы `whlab-theme`**, два состояния переключателя, инлайн-скрипт в `<head>` — не трогается, это уже работает.
- **Весь контент в HTML.** Выключенный JS не должен оставлять пустую страницу.
- **Ни одного цвета и ни одного `rem` мимо токенов** в `style.css` — кроме fluid-шкалы `clamp()` из спеки §4 и `min-height` hero, заданных литерально по спеке.
- **`▋` как глиф не используется.** U+258B не покрыт unicode-range подключённых шрифтов, и `check_font_charset_coverage` упал бы (тот же капкан, что с эмодзи-щитом). Мигающий курсор рисуется CSS-блоком.
- **Старая спека `2026-10-07-landing-design.md` удалена** (уже в worktree) — коммитится вместе с редизайном. Новая спека её заменяет; остаются только её контент и запреты, не отменённые новой.
- **Ассеты не трогаются:** favicon, ogimage, манифест, шрифты, `static/*` — как есть.

## Ключевые решения с расчётом (Rulings, выполненные до плана)

1. **`--accent` = холодный голубой.** Тёмная `#38BDF8`: контраст 8.98 / 8.48 / 7.84 на `--bg` / `--surface` / `--surface-2`. Светлая `#0369A1`: 5.52 / 5.93 / 5.27. Обе темы проходят 4.5:1.
2. **`--signal` = зелёный, только микро-сигналы.** Тёмная `#22C55E` (8.44 на bg), светлая `#166534` (6.63). Используется: щит в hero, подсветка иконки на ховере карточки, hover переключателя темы.
3. **Светлое золото фиксится.** Текущее `#d9a441` на белом даёт 2.25:1 — ниже 3:1 для графики (WCAG 1.4.11). Это предсуществующий дефект, который новая контраст-проверка обязана поймать. В светлой теме `--gold: #8F6419` — 5.24 на `#FFFFFF`, 4.88 на `#F4F7FA`. В тёмной остаётся `#d9a441`.
4. **Токены, уходящие в утиль:** `--accent-hover`, `--surface-hover`, `--border-strong`, `--shadow-sm`, `--radius-sm` — после редизайна на них никто не ссылается, мёртвый токен это ошибка верификатора. Добавляются: `--signal`, `--radius-md: 12px` (аватар), `--radius-pill: 999px` (CTA-пилюли), `--space-section: clamp(4rem, 10vw, 7.5rem)`.
5. **Био-абзац в `about` возвращается по новой спеке §3** («текст из старой спеки, раздел 8»). Это отменяет три строки в `FORBIDDEN_TEXT` старого верификатора («Участник команды», «Active Directory», «Автор каталога из 156») — новая спека сильнее старой.

```python
def _srgb_channel(c: float) -> float:
    return c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4


def _luminance(hex_color: str) -> float:
    """Относительная яркость по WCAG 2.x."""
    h = hex_color.strip().lstrip("#")
    r, g, b = (int(h[i:i + 2], 16) / 255 for i in (0, 2, 4))
    return 0.2126 * _srgb_channel(r) + 0.7152 * _srgb_channel(g) + 0.0722 * _srgb_channel(b)


def _contrast(a: str, b: str) -> float:
    la, lb = _luminance(a), _luminance(b)
    hi, lo = max(la, lb), min(la, lb)
    return (hi + 0.05) / (lo + 0.05)


# Пары (цвет текста, фон, минимум). Текст — 4.5:1 (WCAG 1.4.3), графика — 3:1
# (WCAG 1.4.11). Список проверяется в обеих темах: тёмная берётся из :root,
# светлая — из :root с наложенным [data-theme='light'].
CONTRAST_PAIRS = (
    ("--text", "--bg", 4.5),
    ("--text-strong", "--bg", 4.5),
    ("--muted", "--bg", 4.5),
    ("--muted", "--surface", 4.5),
    ("--accent", "--bg", 4.5),
    ("--accent", "--surface", 4.5),
    ("--signal", "--bg", 4.5),
    ("--signal", "--surface", 4.5),
    ("--tg", "--surface-2", 3.0),
    ("--brand-ink", "--surface-2", 3.0),
    ("--gold", "--surface", 3.0),
)


def check_contrast_pairs() -> None:
    """Все смысловые цветовые пары держат порог WCAG в обеих темах.

    Контраст считается по формуле, а не на глаз: упал ли он — видно только
    числом. Новые акценты (голубой --accent, зелёный --signal) и светлое
    золото проверяются здесь именно поэтому.
    """
    tokens = read("css/tokens.css")
    if tokens is None:
        return

    root_m = re.search(r":root\s*\{(.*?)\n\}", tokens, re.DOTALL)
    light_m = re.search(r"\[data-theme='light'\]\s*\{(.*?)\n\}", tokens, re.DOTALL)
    if root_m is None or light_m is None:
        errors.append("tokens.css: не найден :root или [data-theme='light']")
        return

    def block_of(body: str) -> dict[str, str]:
        return dict(re.findall(r"(--[a-z0-9-]+)\s*:\s*([^;]+);", body))

    dark = block_of(root_m.group(1))
    light = {**dark, **block_of(light_m.group(1))}

    for theme_name, pal in (("тёмная", dark), ("светлая", light)):
        for fg, bg, need in CONTRAST_PAIRS:
            fv, bv = pal.get(fg), pal.get(bg)
            if fv is None or bv is None:
                errors.append(
                    f"контраст {theme_name}: токен {fg if fv is None else bg} не найден"
                )
                continue
            if not fv.startswith("#") or not bv.startswith("#"):
                continue
            ratio = _contrast(fv, bv)
            if ratio < need:
                errors.append(
                    f"контраст {theme_name}: {fg} ({fv.strip()}) на {bg} "
                    f"({bv.strip()}) = {ratio:.2f}, нужно ≥ {need}"
                )
    notes.append("Контраст-пары: проверены в обеих темах")


def check_footer() -> None:
    """Подвал по спеке §3: копирайт + переключатель темы.

    Переключатель переезжает из header в footer — если переезд забудут
    совершить, кнопка темы потеряется, а страница останется «рабочей».
    """
    html = read_if_present("index.html")
    if html is None:
        return
    m = re.search(r"<footer\b.*?</footer>", html, re.DOTALL)
    if m is None:
        errors.append("index.html: нет <footer> — по спеке в подвале копирайт и переключатель темы")
        return
    footer = m.group(0)
    if "data-theme-toggle" not in footer:
        errors.append("footer: нет переключателя темы — он переехал сюда из header")
    if "©" not in footer:
        errors.append("footer: нет копирайта")
    notes.append("Footer: найден, переключатель на месте")


def check_single_column() -> None:
    """Двухколоночный grid отменён спекой §2 — колонок нет нигде.

    Плотность блоков и есть главная боль владельца; вернувшийся grid
    вернёт её незаметно, потому что вёрстка при этом останется рабочей.
    """
    css = read_if_present("css/style.css")
    html = read_if_present("index.html")
    if css is not None:
        if ".grid" in css:
            errors.append("style.css: селектор .grid вернулся — двухколоночность отменена спекой")
        if "repeat(2" in css:
            errors.append("style.css: repeat(2 — признак двухколоночной сетки, отменена спекой")
    if html is not None and 'class="grid"' in html:
        errors.append("index.html: class=\"grid\" вернулся — отменён спекой")
    notes.append("Одна колонка: grid не найден")


def check_hero() -> None:
    """Hero по спеке §5: строка $ whoami, курсор, две CTA-ссылки.

    Дублирование hero CTA + elsewhere разрешено спекой §7 — поэтому
    каждая из двух ссылок обязана встретиться на странице дважды.
    """
    html = read_if_present("index.html")
    if html is None:
        return
    if "$ whoami" not in html:
        errors.append("index.html: нет строки '$ whoami' над именем в hero")
    if "hero__cursor" not in html:
        errors.append("index.html: нет курсора hero__cursor в hero")
    for url in ("https://t.me/wh_lab", "https://github.com/akhomlyuk"):
        if html.count(url) < 2:
            errors.append(
                f"index.html: {url} должна быть и в hero-CTA, и в elsewhere — "
                "по спеке §7 дублирование ссылок допустимо, отсутствие одной из точек — нет"
            )
    notes.append("Hero: whoami, курсор и CTA проверены")


def check_reduced_motion() -> None:
    """Курсор и hover-подъём обязаны отключаться при prefers-reduced-motion.

    Спека §7 требует буквально: и курсор, и подъём выключаются. Если
    правила нет, анимация продолжает мигать у людей с вестибулярными
    нарушениями — тихий дефект, который не виден на обычном прогоне.
    """
    css = read_if_present("css/style.css")
    if css is None:
        return
    m = re.search(
        r"@media\s*\(prefers-reduced-motion:\s*reduce\)\s*\{(.*?)\n\}", css, re.DOTALL
    )
    if m is None:
        errors.append("style.css: нет @media (prefers-reduced-motion: reduce)")
        return
    block = m.group(1)
    if "animation: none" not in block:
        errors.append("reduced-motion: курсор не отключается — нет animation: none")
    if "transform: none" not in block:
        errors.append("reduced-motion: hover-подъём не отключается — нет transform: none")
    notes.append("Reduced-motion: курсор и подъём отключаются")
```
